#👻 GhostText

**GhostText** is a Python-based Command Line Interface (CLI) application for encrypting and decrypting text securely. It provides a simple and lightweight way to protect sensitive messages directly from the terminal.**

> **Note:** This project is intended for educational and personal use.**

---

## ✨ Features

* 🔐 Encrypt plain text
* 🔓 Decrypt encrypted text
* 🖥️ Interactive Command Line Interface (CLI)
* 💾 Save encrypted output to a file
* 📂 Read encrypted text from a file
* ⚡ Fast and lightweight
* 🐍 Written entirely in Python

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/azda-exp/GhostText.git
cd GhostText
```

Install the required dependencies (if any):

```bash
pip install -r requirements.txt
```

---

## 🚀 Usage

Run the application:

```bash
python main.py
```

Follow the interactive menu to:

* Encrypt text
* Decrypt text
* Save encrypted messages
* Load encrypted messages from files
